# ionoi-sites

**Simple website builder for salt-of-the-earth small businesses**

ionoi-sites is a modern, mobile-first website builder designed specifically for small businesses - coffee shops, restaurants, bike shops, lawn care services, and other local enterprises. Built with simplicity and practicality in mind, it integrates seamlessly with the ionoi-such cryptocurrency payment infrastructure.

## Vision

Most small business owners don't need complex enterprise solutions. They need a simple, beautiful website that:
- Works perfectly on mobile devices
- Accepts payments easily
- Can be set up in minutes, not hours
- Doesn't require technical knowledge
- Costs a fair price

ionoi-sites delivers exactly that - nothing more, nothing less.

## Core Features

### 🎨 Pre-Built Templates
Ready-to-use templates for common business types:
- **Coffee Shop** - Menu, hours, location, online ordering
- **Restaurant** - Full menu system, reservations, takeout
- **Bike Shop** - Inventory showcase, repair services, booking
- **Service Business** - Lawn care, cleaning, handyman services
- **Retail Store** - Product catalog, hours, contact

### 💰 Integrated Payments
Direct integration with ionoi-such payment infrastructure:
- Accept Bitcoin, Ethereum, Monero, Solana, and stablecoins
- QR code generation for in-person payments
- Payment page builder
- Simple checkout flows
- No merchant account needed

### 📱 Mobile-First Design
- Responsive layouts that look great on any device
- Touch-optimized interfaces
- Fast loading times
- Progressive Web App (PWA) capabilities

### 🛠️ Drag-and-Drop Builder
- Visual editor - no coding required
- Pre-built components (menus, galleries, contact forms)
- Real-time preview
- Easy text and image updates

### 🚀 One-Click Deploy
- Instant publishing
- Custom domain support
- SSL certificates included
- CDN-backed hosting

## Integration with ionoi-such

ionoi-sites and ionoi-such work together to provide a complete solution:

1. **Build Your Site** - Use ionoi-sites templates and builder
2. **Add Payments** - Connect ionoi-such for crypto payments
3. **Generate QR Codes** - Instant payment codes for in-person sales
4. **Accept Online Orders** - Full e-commerce capabilities
5. **Track Everything** - Unified dashboard for site + payments
